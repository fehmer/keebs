The Koneko40 is a cute 40% keyboard made by Lords Boards. I found this one as an interest check on the 40s Discord.

## Facts

|                      |                                  |
| -------------------- | -------------------------------- |
| **Model no.**        | Koneko40                         |
| **Manufacturer**     | Lords Boards                     |
| **Manufacture Date** | 2024                             |
| **Case**             | CNC'd aluminium                  |
| **Plate**            | Aluminium                        |
| **Switches**         | Gateron Melodic                  |
| **Keycaps**          | PBS Blanks Black                 |
| **Dimensions**       | 240 x 90 x 35 mm                 |
| **Weight**           | 860 grams                        |
| **PCB/Software**     | Koneko PCB, Mill-Max'd, QMK/Vial |

The stars aligned, there was a great sale on HMKB cases, Promenade group-buy started and I found SA Recall for cheap.

## Facts

|                      |                                                                                   |
| -------------------- | --------------------------------------------------------------------------------- |
| **Model no.**        | HMKB 60                                                                           |
| **Manufacturer**     | Heavy Metal Keyboards                                                             |
| **Manufacture Date** | 2024                                                                              |
| **Case**             | Bent steel top and bottom case                                                    |
| **Plate**            | Boardwalk layout, steel+black zink                                                |
| **Switches**         | Durock Blue Lotus T1, 55g                                                         |
| **Keycaps**          | SA Recall                                                                         |
| **Dimensions**       | 315 × 130 × 35 mm                                                                 |
| **Weight**           | 1520 gram                                                                         |
| **PCB/Software**     | [Promenade](https://kradoindustries.bigcartel.com/product/promenade-hs-pcb) + QMK |

## Highlights

I really enjoy the broadwalk layout. The original broadwalk manufacturer closed down and I started working on my own PCB for this layout. Since I never did PCB design before it took a long time working on this on and off. After talking to Lord Boards about it he came up with a design called [Promenade60](https://github.com/LordsBoards/Promenade60). Things slowed down again, then I found a group-buy by Krado Industries called the [Promenade](https://kradoindustries.bigcartel.com/product/promenade-hs-pcb). Luckily this one succeeded and I ended up buying two PCBs from them.
